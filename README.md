# 📊 Crypto Market Analysis Dashboard

## 📌 Project Overview
This project analyzes cryptocurrency market data to identify price trends, trading volume patterns, and volatility using SQL, Python, and Power BI.

## 🛠 Tools & Technologies
- PostgreSQL (SQL)
- Python (Pandas, Matplotlib)
- Power BI
- Jupyter Notebook

## 📂 Project Structure
- `sql/` – SQL queries for analysis
- `notebooks/` – Jupyter notebook with EDA & visualizations
- `powerbi/` – Power BI dashboard file
- `images/` – Dashboard screenshots

## 📈 Key Analysis
- Daily, Monthly, and Quarterly price trends
- High trading volume detection (Top 10%)
- Volatility analysis
- KPI metrics (Avg price, Max, Min, Total Volume)

## 🎯 Insights
- Crypto prices show seasonal behavior across quarters
- High trading volume days correlate with high volatility
- Moving averages smooth short-term fluctuations
